## Implementation Steps
1. **The coverage floor script.** Create `.github/scripts/coverage_floor.py`, stdlib only: it takes the lcov path and
   one or more `CRATE_DIR=PERCENT` floors on its argv, sums `LF` and `LH` over every `SF` record whose path, relative to
   the working directory, lies under each crate directory, and prints one line per crate (for example `packages/escher-driver
   4750/4837 = 98.20 % (floor 97 %)`, two decimals) then a last line: `coverage floor: N of N crates at or
   above their floors` when all hold (exit 0), else `coverage floor: K of N crates under their floors` (exit 1). A
   crate with no `SF` record under it is an error naming the directory (exit 2, never a pass: a floor over nothing
   reads vacuous — the trap test-history records for an unscoped report); a malformed argument is exit 2 with a usage
   line on stderr. It prints no source line and no file path but the crate directory (per obs-plan §9: the lcov holds
   line counts only).
