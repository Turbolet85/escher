## Goal
Give the driver its one definition of what can be asked of it and of how it says no. `escher-driver` gains, in
process and as `'static` data, a closed verb set with each verb's argument and result shapes; a validation that
turns a call into a typed command or a refusal before anything runs; and a closed set of refusal causes, each
with a fixed remedy. Every later surface reads this one table — the actions ("Act by id"), the detection of the
screen-level causes ("Refusal detection"), the span's cause field ("Driver command spans"), the CLI, the MCP
tools and the self-description (per intent §Principles, "the driver's command and refusal model as one schema";
architecture §Standard Contracts → Driver session; security-plan §Input Validation).

Nothing here runs a command, reaches the socket or serves the schema. The verb set is the core five — `snapshot`,
`click`, `type`, `press`, `advance` — in a table the later entries extend with their own verbs when the questions
the route reserves for them are asked (the operator, 2026-10-07, at the P4 forks). `advance` is the answer to the
first carried question: time on a held instance moves when an agent asks for it, in milliseconds, through a step
the session's caller supplies. The second carried question is answered no: no driver command waits on a load.

The chunk claims no capability. v010-11 and v010-14 each need a surface a later entry builds and each is listed on
that entry (Implementation notes, "No capability is claimed").

## Implementation Steps
Files and conventions are research.md's (§New files to create · §Files to modify · §Conventions to follow).

1. **The cause set — `packages/escher-driver/src/refusal.rs` (new).** A public closed enum `Cause` of eight
   causes, in this order, each with a `name` (lowercase, hyphenated — the stub's spelling where the two overlap),
   a one-sentence `meaning` and a `remedy`, all three `&'static str`; a constant listing all eight; `Display`
   printing the name.

   | variant | name | meaning | remedy |
   |---|---|---|---|
   | `UnknownVerb` | `unknown-verb` | the call names no verb of the verb set | use a verb the verb list names |
   | `Malformed` | `malformed` | the call's arguments are not the ones the verb's schema states | pass exactly the arguments the verb's schema names, each of the kind and within the bound it states |
   | `NotFound` | `not-found` | no element on the screen reads the id | take a snapshot and use an id it lists |
   | `Stale` | `stale` | the id read an element earlier in this session and no element reads it now | the screen changed since the id was read: take a new snapshot and act on what it lists |
   | `Disabled` | `disabled` | the element carries the `disabled` attribute, which the snapshot reads as not enabled | the control is disabled: change the state that disables it, then act again |
   | `Covered` | `covered` | another element is hit at the point the action would land | another element covers this one: act on the covering element or dismiss it first |
   | `OffScreen` | `off-screen` | the element lies outside the viewport | the element is outside the viewport: bring it into view, then act again |
   | `TimeUnavailable` | `time-unavailable` | the app this session holds gives it no way to move its time | this session cannot move time: act without `advance`, or start a session whose host supplies a time step |

   The texts above are the stated ones; a rewording is recorded in the report, never silent.
2. **The fault and the refusal — same file.** A public closed enum `Fault` naming which rule a malformed call
   broke: an argument the schema requires is missing; an argument the schema does not name was passed; an
   argument was passed twice; an argument's value is not of its kind; an argument's value is outside its bound.
   Each variant that names an argument holds the SCHEMA's own argument name as a `&'static str` — never a name or
   a value taken from the call; the unnamed-argument variant holds nothing. A public struct `Refusal` holds a
   `Cause` and an optional `Fault` (present only with `Malformed`), with `Display` built from the cause's name,
   its remedy and the fault's fixed words, and `std::error::Error`. Neither type has a `String` field: nothing of
   a call can be in a refusal, by type.
3. **The verb table — `packages/escher-driver/src/schema.rs` (new).** Public `'static` data, no serialization
   crate:
   - an argument kind with five members and the bound each states — `id` (1 to 1024 bytes of text; an author key
     is arbitrary text, so no character class), `text` (0 to 4096 bytes), `key` (one name of the closed key list),
     `flag` (true or false), `milliseconds` (a whole number, 1 to 60 000); the three bounds are public constants;
   - the closed key list, twelve names: `tab` · `enter` · `escape` · `backspace` · `delete` · `space` ·
     `arrow-up` · `arrow-down` · `arrow-left` · `arrow-right` · `home` · `end`;
   - an argument spec (name, kind, required or optional, help) and a result-field spec (name, kind, present always
     or only sometimes, help), the field kinds being text, flag, milliseconds, busy class (`render` · `layout` ·
     `loads`), a list of ids, and a list of nodes whose own fields are stated once (`id` · `parent` · `role` ·
     `name` · `enabled` · `checked` · `value` · `focused` · `bounds` — the diff node's fields, by name only);
   - a verb spec (name, help, argument specs, result-field specs), the constant table of the five verbs in the
     order below, and a lookup by exact name.

   | verb | arguments | result fields |
   |---|---|---|
   | `snapshot` | none | `text` |
   | `click` | `id` (id, required) | the acting fields |
   | `type` | `id` (id, required) · `text` (text, required) | the acting fields |
   | `press` | `key` (key, required) · `shift` (flag, optional) | the acting fields |
   | `advance` | `ms` (milliseconds, required) | the acting fields · `advanced_ms` |

   The acting fields: `settled` (flag) · `busy` (busy class, only when `settled` is false) · `added` (nodes) ·
   `removed` (ids) · `changed` (nodes). A step that ran and did not go quiet is reported here, as `settled: false`
   with its class — it is not a refusal, because the step is not rolled back. `advance`'s help states the unit in
   the schema itself: it moves the app's time forward by `ms` milliseconds and then settles; an app moves time in
   its own units, and `advanced_ms` is the time it actually moved, never more than asked. Help texts name no app,
   no stand type and no element of the stand.
4. **The call and its validation — `packages/escher-driver/src/command.rs` (new).** A call as owned data: a verb
   name and a list of named argument values, a value being text, a whole number or a flag. A public closed enum
   `Command` with one variant per verb carrying its validated values (the key as a member of a public closed
   `Key` enum mirroring the key list), a function from a call to `Result<Command, Refusal>`, and a way from a
   `Command` to its verb spec. The function receives no `Session`. Its order, so every call has ONE answer:
   (a) the verb is looked up by exact name — absent → `UnknownVerb`; (b) the call's arguments in the order given —
   a name the verb's spec lacks → `Malformed` with the unnamed-argument fault; a spec name seen a second time →
   the passed-twice fault; (c) the spec's arguments in the spec's order — a required one absent → missing; a value
   not of the kind → wrong kind; a value outside the bound, or a text that is no name of the key list → outside
   its bound. The first failure in that order is the refusal. No `unwrap`, `expect`, `panic!`, `unreachable!` or
   index on anything a call supplies.
5. **The crate root — `packages/escher-driver/src/lib.rs`.** Declare the three private modules, re-export every

   (`#![deny(missing_docs)]`, `lib.rs:21`). No other file of the crate is edited and no manifest.
