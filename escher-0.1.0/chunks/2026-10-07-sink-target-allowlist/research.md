## Conventions to follow
- **Named prefix sets in the formatter**: a target class is a `pub const … : &[&str]` with a `///` doc, matched by `starts_with`, re-exported from `lib.rs` (`format.rs:13-24`, `lib.rs:30`).
- **Unit tests at the end of the source file**, one `decide`-level test per branch and a subscriber-level test built with `with_default` and a `Capture` writer (`format.rs:167-246`).
- **A process-global behaviour gets its own integration file and its own process**: the parent re-runs `current_exe()` on one `#[ignore]` child with `--ignored --exact {child} --nocapture` and controls `RUST_LOG` on it (`telemetry_stdout_silent.rs:10-14`, `:31-36`).
- **A check that spawns the package's binary**: `env!("CARGO_BIN_EXE_escher-session")`, a state directory under `env!("CARGO_TARGET_TMPDIR")` with a short name, a guard that kills and reaps, every wait bounded, `#[cfg(unix)]` on the test (`host_binary.rs:11-38`, `:68-76`).
- **Helpers shared between test targets are stated once in a subdirectory module** read through `mod {name};` — no test target of its own (`tests/blitz-tests/tests/common/mod.rs`, `tests/blitz-tests/tests/session_common/mod.rs:1-8`).
- **A file-level `//!` doc names the behaviour and the bug it guards** (`host_binary.rs:1-3`, `stand_session_quiet.rs:1-6`).
- **A failing assertion reports a kind and a count, never captured output**: the per-leg CI log is uploaded on failure and the agent-run log keeps raw test output (obs-plan §9, through the obs extract and history). The standing telemetry tests print captured output on failure, but what they capture is synthetic sentinels; the host check captures ids and names.
