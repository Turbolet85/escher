3. **What a session error does not say** (the operator's direction, 2026-10-10, as the arguments of the 2026-10-10-driver-cli wrap). Measured cost (the first live agent trial, 2026-10-10, relayed by the overseer): `state-dir-too-long` on an absolute `--session` path caused 3 of the trial's 3 unintended failures in 49 calls; the agent got past it by guessing a relative path.
   - The thirteen are `SessionError`'s variants, each with a `kind` word (`packages/escher-driver/src/error.rs:12-60`).
     - `StateDirTooLong` is `std` refusing `{dir}/session.sock` as `InvalidInput`, on connect (`client.rs:243`) or on bind (`host.rs:130`).
     - The platform's `sun_path` is 108 bytes on Linux and 104 on macOS, NUL included, so a state directory of at most 94 bytes fits on Linux and 90 on macOS.
     - The path is used as given, so a relative path counts its own bytes, which is why the trial's relative path worked. Read, not run at the edge (research.md, Measured at P3).
