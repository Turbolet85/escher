- **Symbols / APIs:**
  - **The span of a driver command** (new; `packages/escher-driver/src/execute.rs`). Every call handed to `Session::run` opens one `tracing` span: target `escher_driver`, name `command`, level INFO. It is created and entered before `validate` and stays entered until `run` returns, so a refusal `validate` returns is inside it. It is built by hand with `tracing::info_span!` — no `#[instrument]`.
    - **Eight fields, each created unrecorded and recorded only where it applies:** `verb` · `cause` · `settled` · `busy` · `passes` · `added` · `removed` · `changed`.
