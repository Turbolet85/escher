- **Rebase our 16 commits onto upstream:** rejected. The branch is pushed and shared, and the global rules forbid force-pushing.
- **`git merge --squash`:** rejected. It drops upstream ancestry, so every later sync would re-merge these 11 commits and conflict against itself. That breaks "small and often".
- **A `git merge` that commits inside /implement:** rejected. /implement never moves history (plan-template §Test Commands, `leg`). The merge is staged with `--no-commit`, and the operator's pre-CI commit records it.

- **Re-baselining a stand expectation, the viewport, the font or the task CSS to absorb an upstream layout or text shift:** banned per layout-templates §Surface: desktop-native and test-plan §2 Font-dependent tests. A shifted stand check is a halt to name.
- **Re-gating or narrowing the `a11y` leg, or "fixing" the two-way `disabled` keying during conflict resolution:** banned per a11y-plan §9 and §5.
- **Adopting `Node::inline_fragment_boxes` or the iterator-returning `inline_fragment_rects` in escher code now:** out of scope. They are recorded for Snapshot model.
