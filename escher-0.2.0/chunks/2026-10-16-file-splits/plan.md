tool listing, and tool-result writing. `serve_mcp`, the server and the `tool_call` span stay in `mcp.rs`.

it. Each driver file's inline tests move whole into one `#[path]` child file. This is the operator's answer at the P4
fork: «Seams + tests file». Every resulting file stays under 800 tokei code lines.

## Constraints & rejected approaches
- Moving `hover_state_tests` (upstream's module that escher edited) — it is upstream's; moving it rewrites upstream's
  body.

  Contracts → CI contracts).

  the `'static` table that `help` and `tools/list` serve. The shape types are the seam the code has.

  did not come from `validate` (security-plan §Input Validation, Driver command schema row).
- Editing a help string, a verb row, a cause text, a span field or a reply writer during the move — any such edit is a
  plan amendment and possibly a crossing question, never a refactor detail.
