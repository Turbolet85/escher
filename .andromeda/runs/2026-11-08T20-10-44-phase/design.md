- design-system §Surface: cli › Component Patterns (cli-output) requires the exit status to carry the class (`0` accepted · `1` refused · `2` usage · `3` session error), read from the schema's `EXIT_STATUSES` table. A new verb adds no new exit status.

- design-system §Surface: cli › Component Patterns (cli-actions) requires the `actions` line to carry no `NodeId` and to give the same answer on the socket's `call`, over `mcp` and in a kept check. The coverage answer keys on the graph's node id with its optional `owner`, never on a `NodeId`.
- design-system §Surface: web-spa › Component Patterns (web-spa-canvas) records a canvas as one focusable element. The handlers a canvas dispatches internally are therefore not graph handlers, and the canvas limit stated in the acceptance is consistent with this.
