@extract_section name=constraints
- obs-plan §4 Span / Trace Coverage requires every call handed to `Session::run` to open exactly one INFO `command` span at target `escher_driver`, its eight fields closed words, bools and counts only; if the coverage read is a new verb, its `verb` field must be the verb table's own word, recorded alone (as for `graph` / `actions`), and no node id, event name, check path or argument may be fielded.
- obs-plan §4 Span / Trace Coverage requires the MCP `tool_call` span to carry two fields only, `tool` (the verb table's word) and `ending` (`accepted` · `refused` · `error`); a fifteenth tool word is a new closed value of `tool`, and whether the code's verb table already holds such a word is research's question.
- obs-plan §6 Log Coverage requires escher-driver to emit no event and the `Session::actions` read to add no log site; a coverage read built beside it must likewise add no log site, print, env read or clock read, its answer written by `to_json` alone as a command's answer, never a log line.
- obs-plan §8 PII Scrubbing & Compliance requires a graph or actions answer to carry ids, owner ids, closed words and booleans only, never a value, typed text, mask or `NodeId`, kept whole in a recorded check and never logged or fielded; a coverage answer (node id, optional `owner`, handler event name) falls under the same rule and is a boundary widening the founder ratifies.
- obs-plan §3 Observability Harness Contract requires the stand checks and the session library to install no subscriber, read no env var and print nothing (the `stand_act_spans` children and `stand_mcp_tools` recorder aside); the owed `actions`-replay test and any coverage check must join that silence.
- obs-plan §9 CI Integration requires a recording directory to stay local (`0700`, never a log or event line) and committed kept checks to hold no typed text, host path or secret; a check kept by the owed test, if committed, must meet that.
@extract_section name=patterns
- `stand_act_spans` per obs-plan §4 Span / Trace Coverage: one call per layout mode for each verb, its `command` line recording `verb` alone — the pattern a new coverage verb extends.
- `stand_mcp_tools` per obs-plan §4 Span / Trace Coverage: an in-process `Recorder` asserting a `tool_call` parents a `command` span recording its verb alone (as its `actions` test does).
- `host_log` / `mcp_log` per obs-plan §8 PII Scrubbing & Compliance: one call of the verb at `trace` under both builds, reading 0 id, name and verb-specific needles (`actions_needles` in `examples/seven_guis/tests/common/mod.rs`) — the pattern for a coverage verb's needle check.
- `stand_session_recording` / `stand_replay` per obs-plan §3 Observability Harness Contract (absence · logs detail): replay through `Check::replay` with failure messages holding the mode, the file and a step index alone, no subscriber, env read or print — the shape for the owed `actions`-replay test's failure naming the step and differing key.
@extract_section name=anti_patterns
- No logging, fielding or `Debug`-printing of an `Outcome` (a graph, actions or coverage answer) or of a kept check's contents, per obs-plan §3 Observability Harness Contract (session library: `Outcome` written in one place, by `Outcome::to_json`).
- No caller-typed verb text, check path or handler event name recorded on a span, per obs-plan §4 Span / Trace Coverage.
@extract_section name=bindings
- obs ↔ tests: a new verb moves `stand_act_spans`, `stand_mcp_tools`, `host_log` and `mcp_log` (span and needle counts) and the verb-count pins the scope lists; the owed replay test joins the silence census over `tests/blitz-tests/tests/session_common/mod.rs` readers (obs-plan §3 Observability Harness Contract; test-plan §3).
- obs ↔ security: a coverage answer's content (ids, event names) is a boundary widening, the §8 crossing the founder ratifies (obs-plan §8 PII Scrubbing & Compliance).
- obs ↔ cold-agent pipe: a fifteenth tool word reaches the pipe's verb list and `span_counts` only if it is made a counted verb — «Cold-agent bar»'s call (obs-plan §6 Log Coverage).
