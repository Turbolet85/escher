@extract_section name=constraints
- a11y-plan §2 A11y Strategy (Accessibility tree lifecycle) requires the tree to be rebuilt from a poll that takes a non-empty changed set through `Document::accessibility_tree`, so DioxusDocument's stable-id override reaches it; the buffered replay into `MutationWriter` must leave the same `changed_nodes` marks as the direct write did. Whether a replay applied after `render_immediate` marks the same set is research's question.
- a11y-plan §2 A11y Strategy (Accessibility tree lifecycle) states that a focus change marks the changed set; a `set_focus` from a task polled during render, now reachable with no panic, must mark the node so the tree's focus refreshes at the next poll.
- a11y-plan §7 Screen Reader Support (Accessibility tree output) requires every element node in a Dioxus document to carry its stable element id as AccessKit `author_id`, and the tree the shell hands the adapter to equal the harness's tree node for node; the buffer must replay the same element ids in the same order.
- a11y-plan §7 Screen Reader Support (Accessibility tree output) requires `DioxusDocument::snapshot` to take role, name, focus and states from `accessibility_tree`, and the actionable-key rule requires `DioxusDocument::unkeyed_actionable` to return nothing on every stand task; neither may move under the buffered render.
- a11y-plan §5 Keyboard Navigation (Test harness pattern) requires the engine's focus, the snapshot's `focused` node and the tree's focus to agree at every step of `stand_keyboard`'s walks in both layout modes.
- a11y-plan §5 Keyboard Navigation (Focus order per layout) requires HTML's focus fixup (a focused node coming under `inert` gives focus up as the mutator flushes) to keep working; with the flush now done in one borrow after the buffer, whether the fixup still runs at the same point is research's question.

@extract_section name=anti_patterns

- Do not read a fresh harness document's non-empty changed set as proof that the buffered render marked a change; drain first, per a11y-plan §2 A11y Strategy (Accessibility tree lifecycle).
