## Patterns to follow
- A minimal in-file fixture beside the stand where the stand lacks the case: layout-templates §Surface: desktop-native → IA notes records the pinned viewport itself being scrolled only on an in-file fixture taller than it, the stand markup untouched. The `covered` case (scope CARRY 3: no stand control reads it) and the box-in-view `off-screen` case follow that shape rather than growing the stand.
- Geometry stated as a measured reading at the pinned viewport — position and size as (x, y, w × h) for a named id — as layout-templates §Surface: desktop-native → IA notes does for `crud-list` and `task-body`. The fixes' checks assert a box's reading in that form, by stable id, before and after its content is scrolled.
- Elements are addressed by the author ids the plan lists, which add no class, style, wrapper or order and are selected by no task CSS — per layout-templates §Surface: desktop-native → Primary screens (`crud-list`, `crud-filter`, `crud-person-{person.id}` and the rest). Checks name their targets by those ids, never by tree position.
- The test harness's default viewport is 800 × 600 at scale 1 in light mode — per layout-templates §Surface: desktop-native → IA notes. A fixture built for either fix takes that viewport, so its readings compare with the stand's.

## Anti-patterns to avoid
- Making a check pass by moving the stand: adding a wrapper, an `overflow` rule, a class or an id to CRUD or TaskShell so that a box clips or a control is uncovered — layout-templates §Surface: desktop-native → Primary screens and layout-templates §Surface: desktop-native → IA notes both record that no stand markup, id, class or style moved for the scroller's behaviour, and the fix is the engine's.
- Reading a held or hosted instance differently from a fresh boot: layout-templates §Surface: desktop-native → Primary screens requires a held instance to read as a fresh boot, with the TaskShell mount and the pinned viewport holding after commands in both layout modes. A bounds reading that is true only before the first scroll, or only in one layout mode, breaks it.
- Treating `task-body` as the clipping box of a CRUD row to simplify the hit clip — layout-templates §Surface: desktop-native → IA notes records the opposite.
