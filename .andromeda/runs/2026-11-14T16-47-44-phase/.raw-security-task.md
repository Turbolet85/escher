The reference browser app closes the two app-side paths by which a remote (non-file) page still makes the browser read a local file.
The favicon probe: a favicon candidate a non-file document names under a file URL reads no file — the probe carries the loading document as its initiator so the existing file-URL rule refuses it, or it is never started; a file document's favicon still loads.
In-document navigation: a link click or form submission a non-file document starts to a file URL loads nothing; one a file document starts still loads, and the user's own top-level loads are unchanged.
The capabilities document drops its two stale provisional clauses on the founder's rulings, and may state the two closed paths among its limits.
The engine's sub-resource rule is used as it stands; no engine crate changes.
