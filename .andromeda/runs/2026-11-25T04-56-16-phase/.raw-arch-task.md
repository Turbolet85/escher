@task_prose part=chunk
A canvas's taken virtual nodes (key, AccessKit role, name, content-box region, id {owner}///{key}) enter the accessibility tree as children of their canvas's tree node.
From that tree the snapshot reads each as a node (id, role, name, state, bounds) and the snapshot diff names a virtual node added, removed or changed by its id.
The driver's click takes a virtual node's id, acts on its region and returns once settled with the diff, as on an element; its refusals (stale or not-found, then disabled, off-screen, covered) hold for a virtual node in the run path's one order with nothing run.
It carries the founder's names-crossing fork (F3), the declaration-change invalidation and changed-set mark left to the first refreshing reader, and the owed mutation control of the declared chunk's assertion that a declaring canvas puts nothing on the snapshot or graph.
@task_item n=1 part=needs
The accessibility tree build: a canvas's virtual nodes become child tree nodes of its tree node, each with a tree id that collides with no DOM node's id; today each tree node takes its DOM node's id and the build writes no bounds.
@task_item n=2 part=needs

@task_item n=4 part=needs

@task_item n=5 part=needs

@task_item n=6 part=needs
