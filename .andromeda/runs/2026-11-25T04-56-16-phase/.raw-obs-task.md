@task_prose part=chunk
Virtual nodes as elements (v040-11): a canvas's taken virtual nodes, each with a key, role, name, region and the id {owner}///{key}, enter the accessibility tree as children of their canvas's tree node.
From the tree, the snapshot reads them as nodes (id, role, name, state, bounds), and the snapshot diff names a virtual node added, removed or changed by its id.
The driver's click takes a virtual node's id, acts on its region and returns once settled with the diff, as it does on an element.
The driver's refusals hold for a virtual node in the run path's one order with nothing run: stale or not-found, then disabled, off-screen and covered.
It carries F3 (whether a virtual node's name and key cross to the accessible-name and stable-id exits) as the founder's fork, the changed-set marks a declaration change owes, and a mutation control of «a declaring canvas puts nothing on the snapshot or graph».
