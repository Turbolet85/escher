@task_prose part=chunk
A canvas's declared virtual nodes (key, role, name, content-box region, id {owner}///{key}) enter the accessibility tree as children of their canvas's tree node.
From the tree, the driver's snapshot reads them as nodes (id, role, name, state, bounds) and the snapshot diff names a virtual node added, removed or changed by its id.
The driver's click takes a virtual node's id, acts on its region and returns settled with the diff, as on an element; its refusals (stale or not-found, then disabled, off-screen, covered) hold for a virtual node in the run path's one order, with nothing run.
The phase writes every fork, F3 the names' crossing first, to the founder-forks evidence and stops with no default taken.
@task_item n=1 part=needs

@task_item n=2 part=needs

@task_item n=4 part=needs

@task_item n=5 part=needs
