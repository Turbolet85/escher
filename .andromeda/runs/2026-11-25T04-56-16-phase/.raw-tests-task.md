@task_prose part=chunk
Builds virtual nodes as elements: a canvas's declared virtual nodes (key, role, name, content-box region, id {owner}///{key}) enter the accessibility tree as children of their canvas's tree node.
From the tree, the snapshot reads each virtual node as a node (id, role, name, state, bounds) and the snapshot diff names a virtual node added, removed or changed by its id.
The driver's click takes a virtual node's id, acts on its region and returns once settled with the diff, as on an element; stale or not-found, then disabled, off-screen and covered refuse it in the run path's one order with nothing run.
Re-asserts, as a mutation control with its red reading, that a declaring canvas puts nothing on the UI graph, and on the snapshot only as the founder's names' crossing answer allows.
