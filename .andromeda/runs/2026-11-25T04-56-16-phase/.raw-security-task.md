@task_prose part=chunk
A canvas's declared virtual nodes (key, role, name, content-box region; id `{owner}///{key}`) enter the accessibility tree as children of their canvas's tree node.
From the tree, the snapshot reads each as a node (id, role, name, state, bounds) and the snapshot diff names a virtual node added, removed or changed by its id.
The driver's click takes a virtual node's id, acts on its region and returns settled with the diff; the driver's refusals (stale or not-found, then disabled, off-screen, covered) hold for a virtual node with nothing run.
Whether a virtual node's name and key cross today's accessible-name and stable-id exits, the accessibility adapter alone, or neither is the founder's open fork (F3); every surface past the in-process tree hangs on it.
It owes a mutation control of the absence «a declaring canvas puts nothing on the snapshot or graph», which inverts for the snapshot under an F3 answer that carries names and stands for the graph.
@task_item n=1 part=needs
Accessibility tree: virtual nodes added as children of their canvas's tree node, each with a tree id that collides with no DOM node id, carrying role and name; the content classes allowed on the accessibility adapter crossing and the accessibility focus rule (focus names only a built node) apply to these new nodes.
@task_item n=2 part=needs
The names' crossing (F3): a virtual node's name and key leaving through the ratified accessible-name exits, the stable-id exits, the canvas content crossing or the accessibility adapter alone — any new exit is a boundary widening and meets the boundary-widening rule; the founder decides, and the plan writes each option as this entry meets it.
@task_item n=3 part=needs

@task_item n=4 part=needs

@task_item n=5 part=needs
