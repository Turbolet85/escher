@task_item n=1 part=needs
The lint over a canvas: new checks that read the draw commands recorded by the canvas reading of a custom widget, in process, and name a label (glyph run) drawn outside the region meant to hold it.
@task_item n=2 part=needs
How lint findings cross: if canvas findings travel in the lint answer they are new words of its closed defect set, holding no page content, and cross every ratified carrier (socket, MCP, kept check) through the one validation path.
@task_item n=3 part=needs
The canvas content crossing: no glyph id, glyph position, text, font bytes or family name crosses any carrier, whichever carrier a canvas finding takes (the provisional canvas crossing awaiting the founder).
@task_item n=4 part=needs
The boundary widening rule and its carve-out: a new field of a closed value set inside an already ratified carrier is no widening; a new carrier, an open value set or authored text is a widening and so a founder's fork.
@task_item n=5 part=needs
A canvas finding names the canvas element by its stable element id only; it mints no identity for a draw command and uses no virtual-node form of the id, and no NodeId or process-local handle crosses with it.
@task_item n=6 part=needs
The region a label must stay inside: the custom widget's content box it is painted and pointed in, and any clip the widget pushed around the run.
@task_item n=7 part=needs
The glyph run's measured extent: the reading holds glyph origins only, so measuring a label's advance or ink extent would read the font through the document's shared font context handed to the custom widget, a read-only text extent read that answers none when it cannot resolve.
@task_item n=8 part=needs
No new driver verb, carrier, exit code, refusal cause, session error, log field or span unless a founder's fork answer adds one: the closed verb schema, the closed refusal cause set and the fixed session error table stay as they are.
@task_item n=9 part=needs
The lint and canvas reads stay reads: they change no session state, run nothing, never panic on a call's input, and echo nothing the caller supplied.
@task_item n=10 part=needs
If the lint answer or canvas answer changes, the help self-description and the committed capability statement of the crossing change with it, and the kept-check recording keeps the changed answer whole under its owner-only medium.
@task_item n=11 part=needs

@task_item n=12 part=needs
Screen content stays out of logs: no label text, glyph data or finding detail reaches a log line, and the one command span per call keeps its content-free fields.
@task_item n=13 part=needs
