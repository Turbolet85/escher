@history_item n=3 marker=2026-10-12-headless-screenshot
**2026-10-12-headless-screenshot** — (the shot's answer line, no font refused) added a Typography Loading rule: if a driver `screenshot`'s font context resolves no `sans-serif` family, the shot is refused `fonts-unavailable` and nothing is painted, so text is never silently skipped. It also set the shot's `{"width","height","png"}` answer line on the cli surface. This is the precedent closest to a direct test that paints a scene headless and reads its size. It is a trap if the test's document holds text and no font is registered. Note that this rule belongs to the driver's screenshot path, not to the browser's `capture.rs`; the browser's `RenderSize::resolve` path is outside it.
