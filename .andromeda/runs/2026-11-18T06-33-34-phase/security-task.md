Widens the cold-agent pipe's TASK (its fixed stand prompt, or a second task beside it) so a cold agent is asked to use the 0.3.0 reads it can reach over the MCP carrier: graph, actions, layout, caused where a stand step causes one, and the select list; its fifteen-verb tool list stays as it is.
Widens the pipe's span counts to those verbs (a per-verb calls field in the verdict and, where required, a capability-unused reason) and adds closed-word counts of refusals by cause, read from the command span's cause in the server log.
Keeps the wrong-call bar as one named constant whose 0.3.0 value is the founder's, and pins the verdict's judgement at the bar's edge whatever its value.
Extends the offline contract tests (the claude shim and the fake escher-session) over all of this, red before green; the live run, the bar's number and the README and capability-page claims wait on the founder and are written as forks, not chosen.
