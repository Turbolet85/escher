Lets a widget draw canvas text from the bundled fonts, so canvas text on the stand reads the same font as the document's own text; the route a widget takes to those fonts is an operator's fork, never answered by a default.
Writes every operator's fork (boundary widening, new carrier, verb, crossing or public surface, bundled font or asset, a choice that turns what the canvas is) into one forks file in the chunk's evidence, and stops on them.
Runs every check it adds red first, then green, in both layout modes, keeping both readings in evidence with every path respelled; re-reads the CI verdict of the last wrap's commit before the push.
Re-asserts the screenshot's contract and the stand's served tasks' readings, which keep their values unless a ruling moves one.
