@task_prose part=chunk
Places a custom widget at its content box (upstream issue 1578): its paint receives the content-box size and its scene is appended at the content-box origin inside the element's own transform, so it covers its content box exactly with padding, border and a CSS transform alike.
Lets a widget draw canvas text from the bundled fonts, so canvas text on the stand reads the same font as the document's own text, in both layout modes; the route a widget takes to those fonts is an operator's fork, written to the chunk's founder-forks file and never answered by a default.
Every check it adds is run red first (on the tree before the fix, or with the fix reverted) and that red reading is kept beside its green, every path in a kept log respelled with no temp or home path.
Re-reads each widget implementor's paint size and whether any reading moves, and re-reads the last wrap's CI verdict before the push; the screenshot contract and the stand's served-task readings stand.
