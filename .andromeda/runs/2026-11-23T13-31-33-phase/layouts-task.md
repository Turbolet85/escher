@task_prose part=chunk
Measures what a headless shot of a canvas (a widget painted from Rust through Widget::paint) reads on each CI host — linux x86_64, macOS aarch64, windows x86_64 — in both layout modes, as the PNG's bytes and as the decoded RGBA raster, so an encoder difference is told apart from a rasterizer difference.
Puts the measured readings to the founder as one fork in the founder-forks evidence: canvas-shot byte equality across hosts required (amending the no-shot cross-OS rule) or held within a tolerance he sets, with what crosses, the rule it meets, options with measured cost and dependences.
After his word, adds a stand check that holds a canvas shot on every CI OS to that word (equal to one committed table, or within the tolerance), run where the matrix's full test run and the linux test leg already run every stand test target.
Re-measures whether the no-shot rule's stated basis (a shot's PNG bytes differ between linux x86_64 and macOS aarch64) still holds at HEAD for a canvas shot.
