@task_prose part=chunk
Measures what a headless shot of a canvas (a widget painted from Rust) reads on each CI host: linux x86_64, macOS aarch64 and windows x86_64, in both layout modes, as the PNG's bytes and as the decoded RGBA raster, so an encoder difference and a rasterizer difference are told apart.
The measurement reaches macOS and Windows only through CI runs on a pushed build branch; the canvas measured is a stand fixture booted alone, as the earlier canvas shot, placement and text stand checks boot theirs.
It writes the measured readings as one founder fork: canvas-shot byte equality across hosts required (amending the no-shot cross-OS rule) or held within a tolerance he sets, and stops there.
After his word, a stand check holds a canvas shot on every CI OS to that word (equal to one committed table, or within the tolerance), run where the matrix's test step and the linux test leg already run every stand test target.
It adds no driver verb, argument, carrier, result field, refusal cause, session error, exit, log field or span.
