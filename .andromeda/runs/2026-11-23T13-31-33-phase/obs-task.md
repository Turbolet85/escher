@task_prose part=chunk
Measures what a headless shot of a canvas (a widget painted from Rust through Widget::paint, booted alone as a stand fixture) reads on each CI host: linux x86_64, macOS aarch64 and windows x86_64, in both layout modes.
Each reading is taken twice, as the PNG's bytes and as the decoded RGBA raster, so an encoder difference is told apart from a rasterizer difference.
The measurement reaches macOS and Windows only through the CI matrix; the readings and their cost go to the founder as one fork in the chunk's founder-forks evidence: byte equality REQUIRED (amending the no-shot cross-OS rule) or held within a TOLERANCE he sets.
After his word, a stand check holds a canvas shot on every CI OS to that word, run where the matrix's test leg and the linux test leg already run every blitz-tests target.
It adds no driver verb, argument, carrier, result field, refusal cause, session error, exit, log field or span.
