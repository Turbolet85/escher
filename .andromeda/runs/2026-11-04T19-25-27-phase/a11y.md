@extract_section name=constraints
- a11y-plan §7 Screen Reader Support (sr-actionable-keys) requires that no snapshot field say an element reacts to a click. A `.andromeda/residuals.md` line (target: next) owns that reading, and the stand's count of elements that react to input but state no role is its starting reading. Link (2)'s `click` verdict feeds that residual and adds no field (`NODE_FIELDS` stays thirteen).
- a11y-plan §7 Screen Reader Support (sr-author-id) requires every element node of a Dioxus document to carry its stable element id as the AccessKit `author_id`, and the roles and names to be stated once. Any node → component reading must go through that id and leave it unchanged. It must add no second role or name mapping.
- a11y-plan §2 A11y Strategy (accessibility tree lifecycle) requires the tree to be built and refreshed through the `Document::accessibility_tree` trait method, so that DioxusDocument's stable-id override reaches it. A probe hook in `packages/dioxus-native-dom/` must not bypass that override.
- a11y-plan §2 A11y Strategy (`changed_nodes`) says a harness settle neither reads nor drains the changed set, and a fresh harness document's set is non-empty. So if a state → nodes reading leans on `has_changes()` or `take_changed_nodes`, it must drain first. A pointer move, hover or layout marks nothing.
- a11y-plan §5 Keyboard Navigation (keyboard-framework) records the MountedData hazard: a task spawned from a key handler that writes a signal panics at `events.rs:162`. For that reason Cells calls its handles synchronously. The probe must keep Cells' synchronous `MountedData::scroll_to` on arrow moves, and any fix stays the founder's fork. Whether HEAD still has this mechanism and these coordinates after the 2026-11-01 sync is research's question.
- a11y-plan §5 Keyboard Navigation (per-surface keyboard shortcuts) requires Cells' `cells-grid` to be one Tab stop, with arrows moving `current`, clamped, and bringing the cell into view, and Enter opening and committing the editor. It also requires CRUD's `crud-list` keys to move the selection. The probe must leave these SC 2.1.1 / 2.4.3 behaviours on the stand tasks it runs unchanged.
- a11y-plan §1 A11y Scope Summary sets tier 0 (SC 2.1.1 · 1.4.3 · 2.4.3). The probe's test or example code brings no new criterion into scope.
