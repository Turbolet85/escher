@task_prose part=chunk
Takes up five select-list and selection debts of 0.1.0–0.3.0, each first written as a founder fork with its measurement, options and costs into one forks file in the run dir.
The debts: an open select list's highlighted-row contrast (tied to a multiple select's chosen row) unread by the lint's contrast defect; a larger authored font clipping in the list's row height; the highlighted row read by no snapshot and no accessibility tree; a single select's size ignored; Cells' data cells stating no selected reading and no grid role.
For each debt the founder rules fixed, the fix is built in the engine and proven headless on the stand or a fixture in both layout modes; for each ruled kept, the residual is re-stated with his reason.
Re-measures today's readings for each debt (the select popup's painted pair and highlight, row height under the select's font, the snapshot and accessibility tree of an open list, a single select with size above 1, Cells' cell readings) as each fork's measurement.
