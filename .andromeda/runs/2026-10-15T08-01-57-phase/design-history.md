## Relevant amendment history
- **2026-10-10-mcp-surface** — added the `mcp` role to the `escher-session` bullet of §Surface: cli → Component Patterns. Its stdout holds newline-delimited JSON-RPC 2.0 protocol lines only, one reply per request that is not a notification. A `snapshot` result's text is the screen text, and every other result's text is the JSON line. Replies are uncoloured, carry no ESC byte, and no code tests for a terminal. The role's end writes nothing to stdout; an `Err` ending writes its fixed message to stderr with status `3`. The amendment cites the shared `Speaker`, which asserts no ESC byte on every reply, and a no-terminal-test search that counts 0. This is the exact surface the swapped `scripts/cold-agent.sh` hands the fresh session. It is the rule behind the extract's stdout-is-protocol-only constraint and its anti-pattern: a second call count belongs on stderr and is never read from stdout. It is also the rule behind the contract binding that `.github/scripts/test_cold_agent.py` reads replies in that single-line, uncoloured shape.
- **2026-10-12-headless-screenshot** (§Surface: cli part) — in the `mcp` role, a shot is answered with two content blocks: an `image` block (`image/png`, base64), then a text block holding the line without `png`. Every reply is still one line with no ESC byte. The image travelling in band was the founder's fork 1 (2026-10-12). The pipe's tool-answer readers and any completion oracle or call count must read this verb's two-block shape. A cold agent's shot appears in the transcript in this form, which matters for the host-path-masked committed copy.
- **2026-10-12-headless-screenshot** (§Typography → Loading part) — a driver `screenshot` of an app whose font context resolves no `sans-serif` family is refused `fonts-unavailable`, with nothing painted. The stand's bundled font passes. A cold-agent stand task that does not boot through the bundled-font stand boot would turn a `screenshot` into a refusal that the pipe counts as a wrong call. This is the extract's acceptance criterion that a shot is never refused `fonts-unavailable`.

- **2026-10-12-self-description** — the exit status's four classes (`0` · `1` · `2` · `3`) are now read from the schema's `EXIT_STATUSES` table. A fresh agent given only the tool will probably call `help` first, so its answer form and the remedy texts are part of what the agent sees, and that bears on how its wrong calls are classified.
