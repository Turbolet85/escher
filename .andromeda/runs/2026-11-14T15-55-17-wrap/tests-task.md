@task_fact n=1 slug=integration-test-strategy
fact: Exploration is one in-process driver call that boots once to read the first screen (unrecorded, 0 steps), then runs paths of calls off a breadth-first frontier, each on a fresh session, expanding only an accepted path that reaches a screen no earlier path reached; it stops when the frontier empties (exhausted) or the next path would pass the budget.
@task_fact n=2 slug=integration-test-strategy
fact: An exploration's step budget is a whole number from 1 to 10,000 acting calls, re-reach steps counted; 0 or past 10,000 is no budget.
@task_fact n=3 slug=integration-test-strategy
fact: A path ends Accepted (settled or not), Refused with its cause, Panicked, or Diverged at a step; a refused, panicked or diverged path is never expanded, and the report holds no panic payload, node id, screen text or digest.
@task_fact n=4 slug=integration-test-strategy
fact: A panic in a handler during exploration is caught, the panicked session is dropped under a second catch, and the exploration goes on; the next boot on the thread answers.
@task_fact n=5 slug=integration-test-strategy
fact: Exploration explores the verb table's target verbs whose result holds no image field, chosen by the field's kind and never by name; screenshot is never explored.
@task_fact n=6 slug=session-lifecycle
fact: With a recording directory an exploration keeps one check per path, each check's calls equal to its path's answered calls and replaying green; a panicked path's check holds the steps before the panic.
@task_fact n=7 slug=session-lifecycle
fact: A kept check's opening record carries format, written as the integer 1; a check without format reads as format 1; any other value refuses the check as malformed holding nothing of its bytes.
@task_fact n=8 slug=integration-test-strategy
fact: An unbounded app never exhausts an exploration's frontier; exhaustion is asserted only on a finite fixture page, and an exploration of the Counter asserts exhausted false.
@task_fact n=9 slug=unit-test-strategy
fact: A control that removes a bound loosens it (to twice the budget) rather than removing it, so the mutated run stays bounded.
@task_fact n=10 slug=integration-test-strategy
fact: Exploration is reached in process only: no verb, role, argument or carrier reaches it (the founder's own word), and it follows no navigation (provisional).
