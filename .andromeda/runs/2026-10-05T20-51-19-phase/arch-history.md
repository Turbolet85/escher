- **2026-10-05-as-built-baseline** (measured dev-host build environment) — rewrote §Stack and Technologies (Build environment row). The flake is unused, and its rust-bin 1.90.0 pin sits below the workspace `rust-version` 1.91.0. The host runs stable rustc/cargo 1.99.0. There is no `rust-toolchain*` file and no `.cargo/config*`. Why it matters: this row defines the dev host that the "host-reproducible legs run locally" surface targets. Adding a `rust-toolchain*` or `.cargo/config*` (for example, to set debuginfo or a linker) changes this recorded absence and needs an amendment. The amendment's companion `evidence/baseline.md` cold/warm timings are the reference that any cache or profile change is measured against.
