@task_prose part=chunk
Moves the workspace's taffy dependency from the crates.io registry 0.15.1 to upstream's git pin a3997d55 of dioxuslabs/taffy, bringing Taffy #1303 (the caller-defined float id) and the Taffy content of upstream's left-out chain.
Takes the blitz side of that chain as upstream wrote it: 1a11761bc's inline-layout line (the taffy node id as place_floated_box's new first argument) and the code edits of the nine "Bump Taffy" commits, no other upstream pick.
Cargo.lock moves with it: one taffy package from a git source in place of the registry one, every other package only as the move forces.
Before any plan, research re-measures the move in a trial worktree: whether the workspace builds; the fast, clippy, audit, msrv (rust 1.91), doc and build legs, the incremental_oracle, the stand checks and the WPT runner's build; the lock delta; and the wasm legs, the standalone wasm_hello workspace's taffy resolution read on its own.
A red leg with no in-scope fix, an MSRV above 1.91, a broken wasm leg or a refused lock move stops the phase with the measurement; a fork that widens a boundary or needs a rule lifted beyond the Taffy-only exception goes to the forks file and stops it.
