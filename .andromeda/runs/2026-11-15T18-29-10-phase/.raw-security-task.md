@task_prose part=chunk
Moves the workspace's taffy dependency from the crates.io registry 0.15.1 to upstream's git pin a3997d55 of dioxuslabs/taffy, so the tree carries Taffy #1303 (the caller-defined float id) and the Taffy content of upstream's left-out chain.
Takes the blitz side of that chain as upstream wrote it: the inline layout line passing the Taffy node id as place_floated_box's new first argument, and the code edits of the nine "Bump Taffy" commits; no other upstream pick.
Moves the lock with it: one taffy package from a git source in place of the registry one, every other package only as the move forces.
Re-measures before any plan, in a trial worktree: whether the workspace builds; the fast, clippy, audit, msrv at rust 1.91, doc and build legs, the incremental oracle, the stand checks and the WPT runner's build; the lock's package moves; and the standalone wasm example's own taffy resolution.
Stops with the measurement if the move cannot be taken cleanly; a fork widening a boundary or needing a master rule lifted beyond the Taffy-only exception goes to the forks file and stops the phase.
