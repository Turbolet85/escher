## Patterns to follow
- The scrub is an allowlist keyed on target prefix, stated as named sets in the formatter (per obs-plan §8 PII Scrubbing & Compliance → Scrubbing) — a drop rule and any escher-target set follow that shape (a named list, prefix match, one resolution of the target for native and bridged records alike).
- The by-level reading has a recorded form: one fixed scenario (task, `hello`, `stop`), each of default · `info` · `debug` · `trace`, with stderr line count, id needle count, name needle count, the target each came through, and stdout bytes (per obs-plan §8 PII Scrubbing & Compliance → Values logged as-is) — the before/after evidence for both binaries reuses that form so the restated plan line is a like-for-like replacement.
- A check that spawns the real host reads both of its streams into its assertions only, never into a log or a printed line (per obs-plan §3 Observability Harness Contract → Logging stack (subscriber installation), the `host_binary` precedent).
- Every line the sink still prints keeps the one-line text shape with `service.name` / `service.version` (per obs-plan §3 Observability Harness Contract → Service identity and line format, and §6 Log Coverage → Log format (escher's sink)); the sink's own events carry fixed messages with no argv, path or URL (per obs-plan §6 Log Coverage → Logged events (escher-telemetry)) — a new escher-target event, if the plan adds one, follows that.
- The session state directory a host check names holds the socket alone and no log (per obs-plan §9 CI Integration → Telemetry artifact handling, Session state directory) — captured host stderr stays in the test's memory, not in a file beside the socket.

## Anti-patterns to avoid
- obs-plan §11 Obs Anti-Patterns holds no recorded intent, so nothing is cited from it; the bans below are drawn from the sections named.
- Never let the captured stderr of the unfixed host reach a test's failure output: the per-leg CI log is uploaded on failure as unscrubbed build output on the stated ground that it holds no user data (per obs-plan §9 CI Integration → Telemetry artifact handling, Per-leg CI log) — an assertion message reports counts and the matched needle's kind, not the 1.1 MB of lines that carry ids and names.
- Never loosen a rule for a target that still prints in order to keep an existing check green — no content-named field un-redacted, no engine call site edited, no field added to the safe set (per obs-plan §8 PII Scrubbing & Compliance → Scrubbing).
- Never read a sinkless child's silence as coverage of the sink, and never restate the windowed binary or typed text as measured without a by-level reading of it (per obs-plan §3 Observability Harness Contract → Logging stack (subscriber installation) and §8 PII Scrubbing & Compliance → Values logged as-is).
