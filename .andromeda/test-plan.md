- **Invocation:** `bash scripts/agent-run.sh {boot | run {selection} | status | cleanup | logs}` from the repository root (scripts/agent-run.sh:8; scripts/agent-run.sh:163-226); `scripts/agent-run.ps1` is the Windows entry — it passes every argument unchanged to `bash scripts/agent-run.sh` and exits with its code, holding no contract logic, and is not run on the dev host (`pwsh` absent) (scripts/agent-run.ps1:1-4). - **Exit grammar, every verb:** `0` success · `1` the verb ran and failed (a cargo build failure, a failing run, an empty run) · `2` usage (a missing or unknown verb, a wrong argument count, an unknown selection) · `3` a precondition is unmet (not booted; `logs` with no events file); a usage error is checked before not-booted (scripts/agent-run.sh:12-17; scripts/agent-run.sh:176-195)
