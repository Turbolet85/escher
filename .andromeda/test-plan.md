**What unit tests cover:**

- **blitz-test-harness:** `settle.rs` pins the load counter — an answered request reaches the inner handler with its url and bytes and leaves none in flight, a handler dropped unanswered leaves none, the finished count grows by one per handler and never falls, `is_noop` is the inner provider's — the settle loop — an idle document settles in one pass, work for k polls in k + 1, work for ever ends after exactly `SETTLE_PASS_LIMIT` polls as `Render`, a request in flight after a quiet pass reads `Loads` after one poll, a handler finishing inside a pass costs one more pass, a wrapped HTML document is read through its render-blocking resources — and that every `NotSettled` message is non-empty, distinct and holds no `/` (packages/blitz-test-harness/src/settle.rs:193-462)
- **escher-driver:** wire.rs pins the closed lifecycle grammar — `hello v1` and `stop v1` and the four replies round-trip, another version of a known word is `refused version`, anything else (a request line over 64 bytes, bytes that are not text) is `refused malformed`, a reply outside the protocol does not parse, and a line is read up to its terminator and no further, an over-long or unterminated one named; session.rs pins the label rule (1 to 32 bytes of `a-z`, `0-9`, `-`), that an invalid label returns `InvalidLabel` without the boot closure running, and the session's record of ids — the ids read are held, a re-read id becomes the most recently read, and past the bound the one read longest ago is forgotten, on a record of a small stated bound; the bound counts ids, and no test reads an id's length; error.rs pins that every `SessionError` message — the `NotSettled` arm's three, one per `Busy` class, included — is a non-empty fixed string holding no `/`, that an exit code is not in it and that the `Io` arm adds only the kind's name — the arm is spelled "input or output", since "I/O" holds a `/`; refusal.rs pins the closed cause set — eight causes in a stated order, each name, meaning and remedy a fixed text against a stated table, the remedies pairwise distinct and no `/` in any — and a refusal's printed form, which opens with its cause's name and ends with its remedy; schema.rs pins the verb table — six verbs in a stated order, each with help, arguments and at least one result field, the lookup by exact name only (a name differing in case or padding finds nothing), each verb's argument and result shapes, the five kinds with their bounds and the twelve key names, so that an argument or a field of a wait would fail it;
